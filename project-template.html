Hybrid Multi-WAN with OSPF

2024 • Networks, IPv6, OSPFv3, VRRP, Proxmox

Summary

Designed and deployed a redundant hybrid network combining 10 Gbps fibre and Starlink using OSPFv3, VRRP, and VLAN segmentation. Implemented Proxmox virtualization and PBS backups.

Objectives & Context

Build a resilient home/office network capable of automatic failover and high availability during ISP outages or congestion.

Architecture

  • Routing: OSPFv3 across core, VRRP for gateway redundancy.
  • Segmentation: VLANs per zone (workstations, servers, IoT, guests).
  • Virtualization: Proxmox VE cluster, PBS for off‑site backups.

Results

  • Failover < 3 s between WAN links; monitored uptime > 99.99%.
  • Isolated failure domains and clean maintenance windows.

Lessons learned

  • Trade‑offs between OSPF cost tuning and VRRP preemption.
  • IPv6 RA vs DHCPv6‑PD in multi‑WAN environments.

Technologies

  • Ubiquiti UDMP/UDM‑SE
  • OSPFv3
  • VRRP
  • VLANs
  • IPv6
  • Proxmox VE / PBS
