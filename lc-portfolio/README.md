# Lucas Carrasco – Engineering Portfolio

### Publicar en GitHub Pages
1. Crea un repo: `LCS-26.github.io` (sustituye por tu usuario).
2. Sube esta carpeta tal cual a la rama `main`.
3. En **Settings → Pages**, Source = `Deploy from a branch`, Branch = `main` (root).
4. Espera ~1 minuto → URL: https://LCS-26.github.io/

### Añadir un proyecto nuevo
1. Duplica `project-template.html` → ej. `project-ospf.html`.
2. Rellena el contenido y añade imágenes en `assets/img/`.
3. Añade una tarjeta nueva en `projects.html`.

### Personaliza
- Email y enlaces del header.  
- Colores en `assets/css/styles.css`.  
- CV en `assets/CV_LucasCarrasco.pdf`.
